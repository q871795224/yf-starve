# DST Beefalo Skill System

一个围绕骑乘战斗、移动、收获和运输机制开发的《饥荒联机版》模组原型。

## 当前进度

- `mod/` 是模组源码目录，可作为后续本地加载或 Workshop 打包内容。
- 当前原型在牛命中目标后，让骑手播放现有攻击动画，并在动画时间线上用手持近战武器攻击同一目标。
- 骑乘战吼原型使用客户端可配置快捷键请求服务器让牛直接进入原版 `bellow` 状态；目前只有演出，不附加恐惧、跟随或战斗效果，也不新增动画资源。
- 代码和动画表现尚未经过游戏内验证；目前没有配置本地游戏测试环境。
- 技能树、存档进度和其他机制仍在规划中，参见 [项目设计与开发计划](PROJECT.md)。

## 目录

- `mod/`：模组入口和机制代码。
- `PROJECT.md`：设计原则、机制清单和开发/验证计划。
- `temp/`：本地参考资料及工具下载，已由 Git 排除，不属于项目源码。

## 当前原型说明

骑手的攻击是独立于牛攻击的第二次伤害结算。实现复用了游戏已有的 `player_atk_pre` / `player_atk` 动画，没有加入自制动画资源。动画是否适合所有角色、命中帧和多人表现需要在游戏内确认。
